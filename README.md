# jjbits.github.io

Joon's journal on AI and graphics computation — <https://jjbits.github.io/>

Built with [Hugo](https://gohugo.io/) and the [Blowfish](https://blowfish.page/)
theme (a Hugo Module, pinned in `go.mod`). Pushing to `main` builds and deploys
via GitHub Actions.

```bash
brew install hugo                          # extended build, required
hugo server -D                             # preview at localhost:1313, drafts included
hugo new content posts/my-post/index.md    # new post as a page bundle
```

See `CLAUDE.md` for working conventions and `.design/` for status and operations.
